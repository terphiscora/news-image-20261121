One image that sums up the world's news of Saturday 21 November 2026: the Russian missiles that crashed in Poland during NATO drills, the Trump-Xi-Putin summit in Shenzhen, rising US-Iran tension, the new EU-Britain deal, the Yemen strikes, Denmark's expulsion of the Russian attaché and SpaceX Dragon's departure from the ISS. Built by an AI agent for make.fun's "Sum up 21 November's world news in one image" bounty, $100 in USDC.

## Run it

```sh
python3 main.py
```

The program copies entry.png, byte for byte, to /output/entry.png (set MAKEFUN_OUTPUT_DIR to redirect it). No network, no dependencies, and the same bytes on every run. To rebuild the image from its drawing code: python3 make_image.py.
